# 华师舆情监控约定

> 此文件通过 CodeWhale Memory 功能注入到每次对话，CodeWhale 会自动加载。

## 关键文件

| 文件 | 用途 |
|------|------|
| `memory/ccnu-keywords.md` | 关键词映射表（本体词/模糊词/排除词/学院别名）— **每次搜索前必读** |
| `memory/ccnu-conventions.md` | 本文件 — 监控规范和报告要求 |

## 工作定位

为华中师范大学提供跨平台舆情监控与分析服务。

## 监控平台优先级

1. 微博 — 舆情主战场,热搜和话题(已接入 mcp-server-weibo,无需登录)
2. 小红书 — 学生群体口碑(已接入 xiaohongshu-cli,扫码登录)
3. B站 / 公众号 / 知乎 — 通过 web_search/web_fetch 兜底(未接入专用工具)

## 报告规范

- 每日简报在 9:00 前生成
- 异常舆情即时预警（阈值：1小时内同一话题提及量增长 > 200%）
- 报告使用中文，结构化 Markdown 格式
- 必须标注信息来源和可信度
- 负面内容客观呈现，不做价值判断

## 关键词

核心关键词：华师、华中师范大学、CCNU
扩展关键词：桂子山、南湖校区、华师一附中
事件追踪：根据当前热点动态添加

## 数据存储

- 名单/报告/用户/会话持久化在服务端 `server/data/`(JSON 文件,原子写 + .bak),部署时不要覆盖
- 舆情报告:由 Web 工作台「舆情监控」生成并保存到服务端 `reports.json`(上限 50 份)
- 预警/日报:通过 `$content-monitor` 技能生成简报,可保存到项目 `reports/` 目录或邮件发送
